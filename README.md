Real-time Flutter + ESP32-C3 environmental monitoring system. Sensor data streams live over MQTT, with historical charting, threshold alerts, and hardware control from the app.

### 💡 [LumiSense](https://github.com/ashiquekp/flutter-iot-smart-light-system)
Smart lighting automation system with custom embedded C++ firmware — ambient-light sensing, auto-adjustment algorithm, and RGB PWM control, all written from scratch.

`Flutter` `flutter_blue_plus` `PlatformIO` `ESP32-C3` `BLE/GATT`
